# Debugging & Root Cause Analysis

## Definition

Diagnosing the *actual* cause of a problem rather than the surface symptom — following the failure across frontend, backend, config, and tooling boundaries, and verifying the hypothesis against the real system before fixing.

## Proficiency Levels

| Level | Description |
|-------|-------------|
| Working | Fixes the reported symptom with guidance |
| Strong | Independently isolates root cause within a service; verifies the fix |
| Lead | Traces causes across system boundaries; turns each into durable, shared knowledge |

## Growth Notes

Keep verifying assumptions against the running system (staging, the real emailed link, the backend route) rather than trusting that one layer matches another.
