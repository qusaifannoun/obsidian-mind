# Q4 2026

Running log of impact, growth, and collaboration for the quarter. Evidence links to work notes and competencies.

## Impact & Deliverables

- Shipped the frontend for the whole **TAT-314 Forms** epic — four tickets, one flow: a trainee signs up, fills the Application for Training/Examinations and the Type Training Planning Sheet with a signature drawn on screen, a Training Manager approves, and a Super Admin browses every form by course and run. Started against guessed endpoints while the backend was unreachable, then moved the whole thing onto Hamza's real API the day it landed — reading the 1,087-line service rather than guessing a second time — and found it had already **broken the deployed sign-up on staging** (the enroll payload changed and the API rejects unknown fields). Then ran it end to end on staging from all three seats instead of calling a typecheck done: draft enrollment → both forms → catalog → approval → the enrollment really moved to *pending*. That run surfaced and fixed five defects no compile would have caught — signatures uploading as **solid black boxes** (the storage layer converts to `.jpg`, so a transparent canvas turned black), a date-of-birth picker that could not reach a real birth year, a trainee page still saying "waiting" after approval, a list rendering "empty" while its request was merely paused, and page titles unreadable on the banner ([[TAT-481 Super Admin Forms Browser]] · [[TAT-484 Assigned Forms Inbox]] · [[TAT-482 + TAT-483 Enrollment Forms]], [[tat-ws]] `89e6214` + `015a66c`, pushed to dev and prepod 2026-10-11 — **verified on staging; not run on preprod; multi-license fan-out, final enrollment approval and the stamp never exercised**).
- Found the four tickets' **design mockups and the actual approved forms attached in Jira** — absent from the ticket text every pull had used — and rebuilt to them: the declarations copied word for word from the CARC/EASA/GCAA Word files (identical across licenses, so fill-once is sound), the Application's TYPE | B1 | B2 | OTHER table, and the real footer reference numbers, which showed the backend's seeded ones were placeholders ([[TAT-482 + TAT-483 Enrollment Forms]], 2026-10-11).
