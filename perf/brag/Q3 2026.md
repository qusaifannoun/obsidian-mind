## Technical Growth

- **Two official TAT forms rendered as server PDFs on a shared pipeline** — reproduced [[Export History Form - TAT Form 031 PDF|Form 031]] and the landscape [[Export Assessment Report - TAT Form 032 PDF|Form 032]] (14-criterion rubric grid, logo, embedded S3 signatures) from one HTML→Puppeteer→S3 pipeline, verified each against the reference doc by rendering real PDFs. Learned the compose-in-controller idiom for cross-service aggregation without circular DI, and that "Certified by" lives only in the audit log. Evidence: [[Patterns - Backend & Domain#Server-generated form PDFs — reuse the shared Puppeteer pipeline; aggregate cross-service data in the controller]].
- **A reusable button primitive that killed per-call styling drift** — extracted [[History Form Buttons Unified - InlineAction Primitive|InlineAction]] (14 divergent hand-rolled buttons → one tone-based component) and rolled it across History Form, TypeTrainingCourse, and the documents list. Plus a batch of form UX: [[Auto-Populate Instructor Name in Forms|instructor-name auto-fill]], the [[Profile Signature Sign Button|saved-signature "Sign" button]], and [[History Form Online Course Deep-Links|online-course deep-links]] — several enabled purely by noticing the data was already on `/auth/me`. Evidence: [[Code Quality]].
- **Socket.IO consumption invariant** — a real-time client must connect to the API **origin**, not the `/api` REST prefix; auth rides on `handshake.auth.Authorization` (Bearer) and the server rooms by user `_id`. Now captured so the next real-time feature doesn't re-derive it. Evidence: [[Patterns]].
- **Multi-frontend notification routing** — modelled how one backend notification pipeline targets different apps via `resolveClientBaseUrl` + a per-setting `client` tag baked at seed time, and why already-seeded environments need a migration (bootstrap skips existing settings) rather than a reboot. Evidence: [[Patterns]].
