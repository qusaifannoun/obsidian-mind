Caught **two contract bugs invisible from the SA path**: the backend requires a certificate for any non-privileged save, so an instructor's mandatory-training and training-history adds 400'd while SA worked — found only by logging in as the actual instructor. **10 commits** (`0065d3d`, `1f38541`, `29d0d1f`, `68d0e8e`, `b3a9440`, `65d6227`, `1e7b07d`, `ca1c331`, `e1eb0f0`, `276e051`), all tsc + lint clean. Evidence: [[TAT-409 Staff Management Subsystem]], [[Gotchas]], [[Patterns]].

Four pages: Manage Staff (TAT-431), Staff Profile view/add/edit (TAT-432), TOR Matrix (TAT-433), Pending TORs (TAT-435); the TOR Details hub; Initial Documents (TAT-412/413); and all four TOR forms — Form 285 (TAT-414), Form 32 (TAT-415/416), History Form (TAT-417), Assessment Form (TAT-423). **FE-first**: wired to real staging endpoints where they exist (`/user/all`, `/user/details`, `internal-user/signup`, `update-profile`), dummy/stub where the TOR + form backends don't. **13 commits** across `b7f5dcd…e77a2bd`, all green (tsc + lint + build). The remaining 9 tickets are backend-only/other-repo. Evidence: [[TAT-409 Staff Management Subsystem]], [[TAT-432 Staff Profile]], [[Staff Management Subsystem & TOR Model]].
- **TAT-432 — verified Staff create/edit end-to-end against live staging; caught + fixed three silent contract bugs ([[tat-prereq]], 2026-06-07).** The FE-first build had no live backend to test against, so three bugs had shipped unnoticed. Drove the real Add/Edit flows as a Super Admin on `staging.api.tat147.com` (Chrome + direct API probes) and surfaced all three: (1) `nationalIdImage` was optional in the Zod schema but the backend 400s without it on create — fixed with a per-mode `superRefine`; (2) `/file/upload-file` returns `{ Location, Key }` (capitalized) but the FE read `url`/`fileUrl`/`key`, so the image URL came back empty and create failed *even with a file* — a pattern shared across every upload in the subsystem — fixed by reading `data.Location`; (3) `officeLocation` was sent as free text but the backend expects an ObjectId (500 cast) — fixed with a new `src/api/OfficeLocation/` module feeding a select keyed by `_id`. All verified end-to-end on staging; tsc + lint green; merged to `main`. Evidence: [[TAT-432 Staff Profile]], [[Gotchas]].
- **TAT-434 — fixed a silently-broken email verification flow ([[tat-portal]]).** Every verification email was linking to a 404: the frontend only had a path-param route while the backend emails a query-param `/email-verify?token=` link, and the `X-Client-App` header was missing so links targeted the wrong app. Built the correct route + shared `EmailVerification` component + header, removed dead code. Committed `533bf70`. Evidence: [[TAT-434 Email Verification]], [[TAT API & Auth Model]].

Evidence: [[TAT-428 Edit Issued Certificates]].
- **TAT-428 — absorbed a BA re-scope, drove the backend contract change, and rebuilt the cert editor same-day ([[tat-ws]], 2026-06-10/11, commit `d5a6d25`).** The BA rejected the shipped structured-form editor — issued online-course certs must be edited as **rich-text HTML**, mirroring the general editor. Diagnosed why that was impossible (read `tat-app-ws` `origin/dev`: `UpdateOnlineCourseCertificateDTO` had no HTML field; the schema comment confirmed the system was designed for value-editing) and left Hamza a precise Jira ask; he shipped it **same-day**. Rebuilt the FE the same day with **zero duplication**: deleted the superseded modal and reused the general `CertificateEditModal`/Quill editor (the exact UX the BA asked to mirror) via one new `courseType` prop; save errors re-throw so the modal stays open and admin edits survive a failure. tsc + eslint clean. **Closed 2026-07-05: contract-verified against `tat-app-ws` source — the read/write field-name split (`templateHtmlSnapshot` GET → `templateHtml` PATCH → snapshot write, `updateCertificate:665`), the intentional metadata-field strip, and the queue-driven PDF regen from the edited HTML (`:665–672`, `:125`) all confirmed to match the FE; ticket done, archived.** Evidence: [[TAT-428 Edit Issued Certificates]], [[Gotchas]].
