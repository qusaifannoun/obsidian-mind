- **2026-09-09** — **A leading space in a schema `ref` had been 500ing the TOR Matrix, and a missing `isError` branch hid it as "no data".** [[TOR Matrix 500 - Leading Space in aircraftTypeIds Ref]] — started from Qusai asking why the matrix showed nothing in [[tat-prereq]]. `StaffTor.aircraftTypeIds` declared `ref: " TrainingTypes"` — a leading space **and** a model name registered under no spelling (the class is `AircraftTrainingTypes`) — so `getTorMatrix`'s populate threw `MissingSchemaError` and the endpoint 500'd for any result set holding at least one TOR. **The expensive part was the frontend.** `TorMatrixView` destructured only `{ data, isLoading }`, so the crash rendered as *"No staff match your search or filter."* with `EMPTY_SUMMARY` zeros — a server error and an empty result were pixel-identical, and nothing reached the console. A full static trace across both repos disproved permissions, DTO validation, matrix scoping (`STAFF_ROLE_CODES` does include `EX` and `PA`) and adapter null-safety, and still found nothing. **What actually worked was measuring from outside the server**: a browser bisect showing `?search=Accountable` (a user with 0 TORs) returns **200** while the unfiltered query 500s — the signature of a per-row throw — and `performance.getEntriesByType('resource')` at **178–292 ms**, which killed the timeout hypothesis outright. Then **shipping the error state was the diagnostic**: the Mongoose message printed on first render. Two lessons worth more than the bug — **when a list screen shows nothing, verify the component can distinguish failure from emptiness before forming any theory about the data**, because until then the screen is arguing for the wrong answer; and **use `Model.name`, never a `ref` string literal** (`phase.schema.ts` already did, this one site had drifted). Fixes pushed: [[tat-app-ws Backend]] `bad7584f`, [[tat-prereq]] `dcacb9a` — **backend unverified, staging still runs the old code.** Earlier the same session, [[tat-ws]] gained a bulk instructor-by-day-range assign (`155d353` + `29ab123`, **unpushed**) whose candidate list is the intersection of each period's eligible set, which also closed an unfiltered day-level assignment that could pick an instructor the backend rejects.
